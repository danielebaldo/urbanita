About Urbanita

Urbanita is a small, personal city-lookup tool. Type a name, and it pulls together a summary, the key facts, and a map — for places that are actually cities.

What it does

Every search resolves an article on Wikipedia, then checks Wikidata to confirm the result is a settlement — a city, town, village, municipality, and so on — before showing it. If it isn’t, Urbanita says so and offers real alternatives instead of guessing.

How the city filter works

Rather than keeping a hardcoded list of cities, Urbanita asks Wikidata what kind of thing an article is about (its instance of claim), and if that doesn’t directly match a known settlement type, it walks subclass of upward a few hops. That’s how a “commune of France” or a “city-state” resolve correctly without ever being listed by name. Coordinates alone aren’t enough — mountains have coordinates too.

No build step, no backend

The whole site is static files talking directly to the Wikipedia and Wikidata APIs from your browser. No server, no database, nothing to install to run it locally — which is exactly what a free static host like GitHub Pages wants.
